# Architecture Decision Records

This directory preserves decisions whose rationale should survive individual
development sessions. `current.md` tracks transient state and the immediate
next job; ADRs explain durable choices and their consequences.

Use sequential names such as `0003-dashboard-framework.md` with these sections:

- Title and date
- Status (`Proposed`, `Accepted`, `Superseded`, or `Rejected`)
- Context
- Decision
- Consequences

Never rewrite an accepted decision to hide history. Add a new ADR that
supersedes it and cross-link both records.
